# RL Arena — fanouškovský web o Rocket League

Školní projekt vytvořený pomocí HTML a CSS. Web má hlavní stránku, galerii, tipy pro hráče a stránku se zdroji a citací AI.

## Soubory
- `index.html` — hlavní stránka
- `galerie.html` — tematická galerie
- `tipy.html` — tipy pro hráče
- `zdroje.html` — zdroje a citace AI
- `style.css` — společný responzivní vzhled

## Spuštění
Otevři `index.html` v prohlížeči. Pro zveřejnění na GitHub Pages nastav v repozitáři **Settings → Pages → Deploy from a branch → main → /(root)**.

## Citace AI
Použitá AI: ChatGPT od OpenAI. Příklady promptů a externí zdroje jsou uvedené na stránce `zdroje.html`.

## Upozornění
Jde o neoficiální fanouškovský projekt. Rocket League je ochranná známka příslušných vlastníků. Fotografie jsou ilustrační a pocházejí z Unsplash.
